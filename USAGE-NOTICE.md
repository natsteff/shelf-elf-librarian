SHELF ELF LIBRARIAN — APPLICATION DETAILS

Shelf Elf Librarian prepares filenames and can rename, copy or move selected files and rename explicitly selected folders. Applied moves and renames change filesystem locations or names. Undo may be unavailable or refused when files or destinations have changed. Storage failures, interruptions or other software can affect outcomes. Keep backups and review the complete operation preview before applying changes.

This alpha version is under development. It reads MP3 tags as reference information and supported video metadata to supplement missing filename components. Explicitly confirmed MP3 Tools operations or enabled Magic steps can update or remove embedded tags while preserving audio. These tag operations have no Undo or retained file backup. Video metadata remains read-only. Operation history expires after 30 days. Magic proposes interpretations and can remember approved corrections locally; it does not independently execute file operations.
